# RAHIQ Perfumes E-Shop

We are going to build a professional e-commerce website for an Algerian perfume brand called RAHIQ Parfums.

This project must be developed in carefully controlled phases.

Do NOT generate the entire website at once.

Do NOT make assumptions about pages, features, or business logic.

Do NOT add any functionality unless I explicitly request it.

After each phase, stop and wait for my approval before continuing.

I will provide the requirements phase by phase.

Your role is to implement only the current phase exactly as specified.

Do you understand these development rules?
